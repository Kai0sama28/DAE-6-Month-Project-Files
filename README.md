# Kyrell Green's Portfolio & Project Workspace

This repository contains my professional portfolio and the projects I've completed during my 6-month program.

## Repository Structure

- **/docs**: The source code for my GitHub Pages portfolio site.
  - `_config.yml`: Centralized configuration for personal details, career aspirations, and project metadata.
  - `index.md`: The landing page of the portfolio.
  - `about.md`: Detailed information about my background and interests.
  - `projects.md`: Showcase of my top technical projects.
  - `contact.md`: My professional contact information.
- **/Semester2**: Security analysis projects and documentation.
- **/python_1**: Python development scripts and applications.
- **/design_1**, **/figma_1**, **/unix_1**, etc.: Coursework and artifacts from various technical modules.

## How to Personalize the Portfolio

1.  Navigate to the `docs/_config.yml` file.
2.  Update the placeholders (e.g., `[YOUR FULL NAME]`, `[YOUR EMAIL]`) with your actual information.
3.  Add your project details to the `projects` section in `_config.yml`.
4.  Replace the placeholder images in `docs/assets/images/` with your professional headshot and project screenshots.
